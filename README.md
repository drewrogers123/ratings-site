# Disc Golf Elo Calculator

A React application for calculating and managing disc golf player ratings using the Elo rating system.

## Features

- Calculate Elo ratings for disc golf players
- Import/export data from Excel files
- Configurable rating parameters
- Visual rating history and statistics
